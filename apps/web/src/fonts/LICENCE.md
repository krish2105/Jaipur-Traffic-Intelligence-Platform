# Fonts

**Clash Display** — Indian Type Foundry, via Fontshare.
ITF Free Font Licence: free for personal and commercial use.
https://www.fontshare.com/fonts/clash-display

Self-hosted deliberately rather than loaded from Fontshare's CDN: a deployed
artefact's CSP blocks external font hosts, and docs/03 §5 requires the demo to
run with the network cable pulled.

**Anek Devanagari / Anek Latin** — Indian Type Foundry, via Google Fonts (OFL).
Loaded through `next/font/google`, which self-hosts at build time.

Both families are from the same Indian foundry. For a Government of Rajasthan
product that is a better story than a pairing of convenience, and it is why
Anek was kept rather than replaced.

**JetBrains Mono** — JetBrains, OFL, via `next/font/google`.
